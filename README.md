# 🐧 Linux File Manager



A beginner-friendly command-line file management application built using **Bash scripting on Linux**.



Linux File Manager makes everyday file and directory operations easier through a simple interactive terminal menu.



## 🚀 Features



- 📁 List files and directories

- 📂 Create new directories

- 📄 Create new files

- 📋 Copy files

- 🚚 Move files between directories

- 🗑️ Delete files

- 🔍 Search for files

- ⚡ Simple interactive command-line interface



## 🛠️ Technologies Used



- Linux (Ubuntu)

- Bash Scripting

- Linux Command-Line Utilities

- Git \& GitHub



## 📋 Requirements



Before running this project, make sure you have:



- Linux operating system (Ubuntu recommended)

- Bash shell

- Git (optional, for cloning the repository)



## 📥 Installation



**1. Clone the repository**



```bash

git clone https://github.com/YOUR\_USERNAME/linux-file-manager.git

```



**2. Navigate to the project directory**



```bash

cd linux-file-manager

```



**3. Give execution permission**



```bash

chmod +x main.sh

```



**4. Run the application**



```bash

./main.sh

```



## 💻 How to Use



After running the application, an interactive menu will appear.



```text

================================

      LINUX FILE MANAGER

================================



1. List files

2. Create directory

3. Create file

4. Copy file

5. Move file

6. Delete file

7. Search file

8. Exit



Enter your choice:

```



Choose an option and follow the instructions displayed in the terminal.
